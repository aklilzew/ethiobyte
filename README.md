# Ethiobyte — Digital Solutions Platform
A modern, responsive web application built with **React 19**, **Tailwind CSS**, and **Framer Motion**.
## 🚀 Key Features
- **Responsive UI/UX:** Built with Tailwind CSS and Headless UI for seamless mobile and desktop browsing.
- **Fluid Micro-Interactions:** Smooth animated transitions powered by Framer Motion.
- **REST API Integration:** Orchestrated data fetching using Axios.
- **Dynamic Routing:** Multi-page client-side navigation using React Router.
## 🛠 Tech Stack
- **Frontend:** React 19, JavaScript (ES6+), Tailwind CSS, Headless UI
- **Animations:** Framer Motion, Slick Carousel
- **HTTP Client:** Axios
- **Icons:** Lucide React, React Icons
